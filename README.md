# Codex 新手入门指南

按下面三个部分，完成网络准备、账号注册和 Codex 桌面版使用，在 Codex 里使用 GPT 模型。

## 第一部分：访问外部网络

1. 打开[网络服务注册入口](https://dashboard.miaogic.org/#/auth?invite=uSvlw3fc8h)，按页面提示注册账号并登录。
2. 找到站内使用教程，选择自己设备对应的教程，例如 Windows、Mac、安卓或 iPhone。
3. 按教程完成软件下载、配置和连接。如需开通套餐，费用与付款方式以网站页面为准。

## 第二部分：注册 GPT 的账号

1. 打开 [ChatGPT 官网](https://chatgpt.com/)，点击“注册 / Sign up”。
2. 使用自己的邮箱，按页面提示完成注册和邮箱验证。已有账号可以直接登录。
3. **如果提示手机验证**，选择号码所属国家或地区，填写受支持的手机号码，接收短信验证码并填入页面。号码不一定要美国的。

如果没有可用的手机号，**可以去一些 GPT 充值网站了解接码服务，部分网站也提供接收验证码的服务**。

手机验证并非人人都会遇到，也可能在进入 Codex 时出现；没有提示就继续下一步。[查看官方验证说明](https://help.openai.com/en/articles/8983040-what-does-phone-verification-look-like)

## 第三部分：下载使用 Codex

1. 打开 [Codex 官网](https://openai.com/codex/)，按提示下载适合自己电脑的桌面版。
2. 安装并打开，用刚才注册的 ChatGPT 账号登录。如果出现手机验证提示，按第二部分的说明完成验证。
3. 进入 **Codex**，新建对话，在输入框下方的模型菜单中选择账号可用的 **GPT 模型**。
4. 输入问题或任务，点击发送，就可以开始使用了。例如：“帮我做一个简单的个人介绍网页。”[查看模型选择说明](https://learn.chatgpt.com/docs/models?surface=app)

目前新版桌面应用统一使用 ChatGPT 名称，安装后选择其中的 **Codex** 入口即可。[查看官方说明](https://help.openai.com/en/articles/20001276-moving-to-the-new-chatgpt-desktop-app)

> 地区说明：中国大陆目前不在 OpenAI 官方支持地区列表中；所以外部网络的ip选择最好是美国、新加坡、日本或者台湾等地区。
